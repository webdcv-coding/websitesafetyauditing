HARDENING STEPS

If you’re missing these, moving your site to Cloudflare is the easiest way to fix them without touching server code.

1. SSL/TLS Mode Set to Full (Strict) in SSL/TLS > Overview. (Ensure origin has a valid cert).
2. Enable HSTS In Edge Certificates, toggle HSTS to ON with Subdomains & Preload active.
3. Security Headers Create a Transform Rule to add:
  • • X-Frame-Options: SAMEORIGIN
  • • X-Content-Type-Options: nosniff
